# Where the f I am?

Chinese id

把模糊意图翻译成可执行约束的能力，阅读和判断代码的能力，以及理解媒介默认值并反抗它们的能力。编程课如果还有未来，不是因为我们要和机器比赛写代码，而是因为我们要在代码成为材料之后，仍然保有作者的位置。

English ver

The ability to translate vague intentions into executable constraints, the ability to read and evaluate code, and the ability to understand media defaults and resist them. If there is a future for programming classes, it is not because we want to compete with machines in writing code, but because we want to retain our position as authors even after code becomes a material.
